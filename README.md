# GreenSpace NM - Northern Metropolis Green Space Interactive Platform

Hackathon Demo project: an interactive web platform that transforms official text-based green space planning documents into a visual map for the Northern Metropolis (Hong Kong).

## Features

- **Interactive Green Space Map** - SVG-based clickable zones with detail panels
- **Resident Survey** - 4-step questionnaire with progress tracking
- **AI Opinion Heatmap** - Spatial visualization of aggregated public feedback
- **Government Dashboard** - KPI cards, Chart.js bar/pie charts, data table
- **Trilingual Support** - English / 简体中文 / 繁體中文 with live language switching

## Tech Stack

- HTML5 + CSS3 (single file, self-contained)
- Vanilla JavaScript (no build tools)
- Chart.js 4.4.1 (CDN)
- Custom SVG map visualization
- localStorage for language preference

## Usage

Open `index.html` in any modern browser. No server required.

## File Structure

- `index.html` - Self-contained single-file demo (all CSS + JS inlined)
- `i18n.js` - Translation dictionaries (EN / zh-CN / zh-TW), reference only
- `app.js` - Application logic, reference only
